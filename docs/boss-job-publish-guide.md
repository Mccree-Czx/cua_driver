> 生成于 2026-10-16。数据源：猎聘 `GET /api/jobs`（5 个在招岗位，全部 active）。
> 表单锚点由真机 `uiautomator dump` 实测，见 `agent_boss/boss_map.json`。

## 为什么这一步要人工发

自动发布**这次做不到**，四条理由：

1. **第二页「选择职位要求」的字段没探到**（要填了必填项才能翻过去），流程写不出来。
2. 这个 BOSS 账号**刚被风控判过异常、刚过完人脸识别**，紧接着用脚本批量发职位，再次触发风控的概率很高——而封号不可逆。
3. **发布是公开且不可逆的动作**。
4. 字段不是一一对应的（见下表），中间需要人的判断。

## 猎聘 → BOSS 字段映射

| BOSS 字段 | 猎聘来源 | 换算说明 |
|---|---|---|
| 招聘类型 | 无 | 这批全是社招 → 选 **社招全职** |
| 职位名称 | `title` | 直接照抄（★ 发布后不可修改） |
| 职位描述 | `jd_text` | 直接照抄（原文见下方各岗位） |
| 工作城市 | `location`（如 `上海-虹口区`） | ★ BOSS 要**商圈/街道**级（现有职位是 `上海·四川北路`），区级不够，需你选到商圈 |
| 薪资 | `salary`（如 `30-50k·13薪`） | BOSS 显示是全大写 `K`（`18-25K·13薪`），换算时注意 |
| 经验 | `experience`（如 `3年以上`） | ★ BOSS 用**区间**（`3-5年`/`5-10年`/`1-3年`），不是「N年以上」，要选档 |
| 学历 | `education`（如 `本科`） | 直接对应 |

## ★ 注意事项

- **发布后不可修改**的字段：`招聘类型` / `职位名称` / `职位类型` / `工作城市`（页面原文提示）。职位名和城市发出去就定死了，想改只能下架重发。
- **退出表单时会弹一个引导框**（「AI帮我写 / 复制历史职位」），**它不是丢弃确认**。真正的关闭入口是弹框下方的 `iv_close`（约 540,1599），关掉后再按 BACK 才是干净退出。
- 这个账号**已有 3 个职位**（2 个「待开放」、1 个「已关闭」），是发新职位前就存在的，别误以为是这次留下的草稿。
- BOSS 免费招聘账号的**在招职位数有上限**，发之前先确认配额。
